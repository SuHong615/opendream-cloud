# OpenDream Cloud 用户旅程分析

> 修正：AgentCore 运行时、AgentLoop 质量闭环、OpenCode Harness 云边工程、LoopForge 编排、数字军团指挥中心应用层。
> 总纲：[AI Native OS](AI-NATIVE-OS.md)

## 1. 用户与工作台

| 用户 | 工作台 | 核心任务 |
| --- | --- | --- |
| AI Native Builder | OpenCode Harness | 构建/接入/分享应用 |
| 领域专家/角色设计师 | LoopForge | 流程识别角色、角色数字人、军团 |
| 开发者 | AgentCore/Harness | 扩展运行时、工具、MCP |
| 质量/平台工程师 | AgentLoop | 观测、评测、实验、安全、回测 |
| 指挥官/业务负责人 | 指挥中心 | 指挥、干预、复盘 |
| 平台/IT | 能力/治理 | 私有化、权限、成本、安全 |
| 高管 | 指挥中心组合 | 价值与转型 |

## 2. 旅程一：Builder 构建应用

```text
想法 → OpenCode Harness 新建 → 选模型/MCP/模板
→ 云端/桌面构建 → 运行 → 分享团队 → 复用
```

| 阶段 | 触点 | 设计机会 |
| --- | --- | --- |
| 新建 | Harness 工作区 | 模板/样例 |
| 接入 | 模型/MCP 选择 | 推荐组合、连通测试 |
| 构建 | 编辑器/画布 | 实时预览、错误定位 |
| 验证 | 运行面板 | Trace/结果 |
| 分享 | 分享抽屉 | 链接/权限/版本 |

**MOT**：第一个可分享应用。**指标**：< 30 分钟。

## 3. 旅程二：领域专家定义角色数字人

```text
流程 → 识别角色 → 定义 Role → 绑定 SOP 节点
→ 试运行 → 发布 → 军团复用
```

| 阶段 | 触点 | 设计机会 |
| --- | --- | --- |
| 流程 | LoopForge 画布 | 从流程节点推荐角色 |
| 角色 | 角色编辑器 | 模板、从 Run 沉淀 |
| 绑定 | 节点属性 | 角色×工具×模型 |
| 验证 | AgentLoop 评测 | 评测门禁 |
| 发布 | 版本 | 引用/影响分析 |

## 4. 旅程三：指挥官指挥军团

```text
任务 → 编成军团 → 下达战役
→ AgentCore 执行 → AgentLoop 质量监控
→ 指挥中心态势 → 干预 → 审批 → 复盘
```

| 阶段 | 触点 | 设计机会 |
| --- | --- | --- |
| 任务 | 指挥中心 | 目标/验收/预算 |
| 编成 | 编排 | 推荐军团/SOP |
| 监控 | 数字孪生战场 | 卡点/风险高亮 |
| 干预 | 指挥台 | 暂停/退回/接管 ≤ 3 点击 |
| 复盘 | 复盘报告 | 自动沉淀 |

## 5. 旅程四：质量工程师使用 AgentLoop

```text
Trace → 评测 → 实验 → 安全策略 → 沙箱/回测
→ 发布门禁 → 生产观测 → 反馈
```

| 阶段 | 触点 | 设计机会 |
| --- | --- | --- |
| 观测 | AgentLoop | 失败链路 |
| 评测 | 数据集/评测器 | 基线/回归 |
| 实验 | A/B | 显著性 |
| 安全 | 策略 | PII/越权 |
| 回测 | 历史回放 | 发布前验证 |

## 6. 旅程五：开发者扩展平台

```text
AgentCore SDK/MCP → 本地/云端开发 → 契约测试
→ 发布 → AgentLoop 门禁 → 生态
```

## 7. 旅程六：管理员建设底座

```text
部署 → 身份 → 模型/MCP → 配额/审计 → 观测/扩容
```

## 8. 当前断点

1. 只有 LoopForge 一个入口，平面没有独立工作台；
2. AgentCore/AgentLoop 概念未在产品中体现；
3. 指挥中心只有概览，没有数字孪生态势/干预；
4. OpenCode Harness 云边未统一；
5. 角色/员工/军团/小队概念重叠；
6. 质量闭环分散。

## 9. 指标

| 指标 | 目标 |
| --- | --- |
| Builder 首个应用 | < 30 min |
| 角色复用率 | > 40% |
| 军团完成率 | > 80% |
| 指挥干预 | ≤ 3 点击 |
| AgentLoop 门禁覆盖 | 100% |
