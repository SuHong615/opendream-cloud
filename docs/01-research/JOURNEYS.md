## 0. 统一错误码表（旅程中引用）

> **两层错误模型（与 `openapi.yaml` 对齐）**：产品码为 **UPPER_SNAKE**（本文档/PRD 使用，供人读与测试断言）；wire `error.reason` 为对应 **lower_snake**；`error.code` 用通用枚举（`unauthorized`/`forbidden`/`not_found`/`quota_exceeded`/`precondition_failed`/`orchestrator_unavailable` 等）。`EVAL_GATE_FAILED` 的 wire reason 为 `gate_blocked`。**鉴权语义统一（B8）：跨租户或资源不存在 → 404 `not_found`；同租户无权限 → 403 `forbidden`。**

| 产品码（UPPER_SNAKE） | wire reason（lower_snake） | HTTP | 含义 | 用户可见文案要点 |
| --- | --- | --- | --- | --- |
| `AUTH_SESSION_EXPIRED` | `auth_session_expired` | 401 | SSO 会话过期 | "登录已过期，请重新登录"并保留原目标 URL |
| `AUTHZ_FORBIDDEN` | `authz_forbidden` | 403 | 同租户无权限（跨租户为 404） | "你没有该资源的访问权限" + 申请入口 |
| `WS_LAUNCH_TIMEOUT` | `ws_launch_timeout` | 504 | 工作区拉起超时（>180s） | 展示失败阶段 + 重试按钮 + 诊断码 |
| `WS_QUOTA_EXCEEDED` | `ws_quota_exceeded` | 409 | 工作区配额超限 | 显示当前用量/上限/申请提升入口 |
| `WS_IMAGE_PULL_FAILED` | `ws_image_pull_failed` | 502 | 镜像拉取失败 | 提示平台侧问题 + 自动重试 1 次 |
| `MODEL_NOT_AUTHORIZED` | `model_not_authorized` | 403 | 模型未授权给该用户/组织 | 列出可用模型替代 |
| `MODEL_BUDGET_EXCEEDED` | `model_budget_exceeded` | 429 | 模型预算/配额耗尽 | 显示剩余额度与重置时间 |
| `SKILL_PERMISSION_DENIED` | `skill_permission_denied` | 403 | Skill 声明权限超出授权/需审批 | 逐项列出被拒权限 |
| `EVAL_GATE_FAILED` | `gate_blocked` | 409 | 评测未达基线，禁止上架 | 通过率/失败用例 Top5 |
| `SHARE_LINK_EXPIRED` | `share_link_expired` | 410 | 分享链接过期/被撤销 | "链接已失效" + 联系所有者 |
| `APP_BUILD_FAILED` | `app_build_failed` | 200（业务态 failed） | 应用构建失败 | 日志末尾 + 重试 |
| `MCP_HEALTH_DOWN` | `mcp_health_down` | 503 | MCP 不可用 | 降级说明 + 工具暂不可用 |
| `MCP_AUTH_REQUIRED` | `mcp_auth_required` | 401 | MCP 需要 OAuth/凭证 | 一键授权入口 |
| `NOT_FOUND`（跨租户/不存在） | `not_found` | 404 | 跨租户或资源不存在（不泄露存在性） | 统一"资源不存在或无权访问" |

> 角色命名以 PLAN R1.2 为准：`owner/admin/member/viewer`（控制台另有 `team_owner`/`org_admin`/`author`/`app_user`/`platform_admin` 视角标签，见 IA §1.1）。入口路径以 IA §2.2 为准：工作区 `/workspaces/:id`、Skill `/skills`、评测 `/evals`、应用 `/apps`、分享 `/apps/:id/share`、MCP `/mcp`、用量 `/usage`、审计 `/audit`、应用门户 `/a/:slug`。

## 2. 端到端旅程

### J1 首次登录 → 自动拉起 4C8G 工作区 → 开始对话

| 项 | 内容 |
| --- | --- |
| 角色 | P1 终端开发者 |
| 触发 | 收到邀请邮件/企业微信通知，点击平台链接 |
| 前置 | 组织已开通、用户已在 IdP 中、C1/C2 档位资源可用（镜像缓存/预热占位 Pod，见 PRD E3-02） |
| 频率 | 每人仅一次（首次），但**冷启动路径每天都会复用** |

| # | 用户动作 | 系统反馈 | 系统行为（内部） |
| --- | --- | --- | --- |
| 1 | 打开 `https://cloud.example.com` | 302 到企业 IdP 登录页 | 生成 state/nonce，记录来源 URL |
| 2 | 在 IdP 输入账号密码/扫码 | IdP 回调平台 | 校验 ID Token（签名/iss/aud/exp），创建平台会话（HttpOnly Cookie），落审计 `login.success`；**登出/全局登出走 `POST /auth/logout`（204 + IdP end_session），全设备失效 ≤5s（PRD E1-01④⑥）** |
| 3 | 首屏显示"正在为你准备工作区"进度页 | 阶段条：`分配资源 → 拉取镜像 → 启动引擎 → 就绪`；每阶段 ≤2s 推送 | 创建 `OpencodeWorkspace` CR；调度 Pod（4C8G）；挂载 PVC；注入配置（模型/技能/MCP）；等待 readinessProbe |
| 4 | 进度页显示"就绪，正在进入" | **新标签页**打开 `https://w-<short>.ws.<domain>/`；当前页提示"已在新标签页打开" | 控制面 `POST /access-ticket` 签发 60s 一次性票据 → 新标签页 `?ticket=` → 网关验签 → 302 去掉 ticket；**Basic 仅 gateway→上游内部注入**（ADR-005/D15），浏览器不可见；SSE 断线自动重连（可见连续性，D18） |
| 5 | 在工作区 Web GUI 输入第一条需求 | 流式返回模型输出；工具调用可见 | opencode serve 调用 LiteLLM（虚拟 Key）→ 供应商；用量事件回传计量 |
| 6 | 结束 | 无"退出销毁"提示 | 记录 `workspace.ready` 用时、首 token 时延 |

**异常路径**

| 场景 | 系统行为 | 用户可见 | 验收点 |
| --- | --- | --- | --- |
| K8s 无可用节点/资源不足 | 排队 ≥30s 后进入 `starting` 慢路径；>180s 判失败 | `WS_LAUNCH_TIMEOUT` + 失败阶段 + "重试" | 失败必须给出阶段与诊断码；重试不重复扣配额 |
| 镜像拉取失败 | 自动重试 1 次（退避 5s） | `WS_IMAGE_PULL_FAILED`，提示平台侧问题 | 重试后仍失败需告警给管理员 |
| 用户中途关闭页面 | 拉起任务**继续**（不取消） | 下次进入直接命中"就绪" | 后台继续拉起，R3.9 |
| SSO 回调 state 不匹配 | 拒绝登录，回到登录页 | `AUTH_SESSION_EXPIRED` 风格提示 | 不得泄露 IdP 错误细节 |
| 用户属于组织但无工作区配额 | 不创建 CR | `WS_QUOTA_EXCEEDED` + 申请入口 | 错误发生在创建前，避免浪费资源 |
| SSO 回调 state 不匹配 | 拒绝登录，回到登录页 | `auth_session_expired`（不展开 IdP 错误细节） | 不得泄露 IdP 错误信息 |

**成功指标**：首次登录→可交互 P95：**C1 ≤90s / C0 ≤180s**（E3-02 三档）；登录成功率 ≥99%；**进度页离开率为观测指标（不作门禁，允许离开后台继续）**；首 token P95 ≤ 5s；`workspace.launch_fail_rate` ≤ 1%（漏斗 S2 指标，不计入 WSS）。

**对应 PRD**：PRD-E1-01、PRD-E3-01、PRD-E3-02、PRD-E3-04、PRD-E3-08、PRD-E8-02

### J2 关闭浏览器数小时后回来 → 工作区仍在、会话可继续

| 项 | 内容 |
| --- | --- |
| 角色 | P1 终端开发者 |
| 触发 | 午饭/会议后重新打开平台或直接打开收藏的工作区域名 |
| 前置 | 工作区此前已 ready；PVC 持久；未开启休眠（默认关闭） |
| 频率 | 每日 3–8 次（最高频旅程） |
| 状态语义 | 直接引用 openapi `WorkspaceState` 9 态：`idle`=ready 子态（可直接进入，无需唤醒）；`stopped`=已休眠（需唤醒）；`starting`+`reason=restore`=Pod 重建恢复中；`error`=失败（带 reason）；`deleting/deleted`=销毁流程。GUI surface 与 console surface 分离：本旅程 1–4 步在 **opencode GUI（子域名）**，第 5 步在**控制台工作区详情页** |

| # | 用户动作 | 系统反馈 | 系统行为 |
| --- | --- | --- | --- |
| 1 | 打开工作区 URL | ≤2s 内进入（若 Pod 仍在）；若因节点回收重建则显示"恢复中" | 网关校验会话；查询 CR 状态 |
| 2 | （Pod 被驱逐场景）看到"正在恢复你的工作区" | 阶段：`恢复数据 → 启动引擎 → 就绪`，P95 ≤ 90s | 重新调度 Pod，挂载同一 PVC，注入同一配置 |
| 3 | 打开会话列表 | 历史会话、消息、文件树完整 | opencode 从持久存储恢复 session 数据 |
| 4 | 继续上次对话 | 上下文按策略恢复（见开放问题 Q6） | 读取 session message 历史；模型调用继续计量 |
| 5 | 查看成本提示 | 工作区页显示"常驻 4C8G · 今日运行 6.2h · 约 ¥x"与"闲置休眠"开关 | 计量服务聚合资源时长 |

**异常路径**

| 场景 | 系统行为 | 用户可见 | 验收点 |
| --- | --- | --- | --- |
| PVC 挂载失败 | 重试 3 次，仍失败则标记 `error` | `ws_storage_attach_failed` + "数据未丢失，请联系管理员" | 明确承诺数据不丢，且给出工单入口 |
| 会话数据损坏 | 降级为"仅恢复文件，会话列表为空" | 显式提示"部分会话不可恢复" | 不得静默丢失；提供导出入口 |
| 用户已离职/被禁用 | 拒绝进入 | `AUTHZ_FORBIDDEN` | 工作区保留策略见 R10.3，需管理员处置 |
| 工作区已被用户自己销毁 | 显示"工作区已销毁" | 明确不可恢复提示 + "重新创建"（新 PVC） | 销毁需二次确认，见 R3.3 |
| 平台已对该工作区开启休眠 | 显示"正在唤醒" | 唤醒 ≤30s；数据完整 | 休眠默认关闭，开启后需在设置页明示 |

**成功指标**：回访进入 P95 ≤ 5s（Pod 存活）/ ≤ 90s（重建）；"数据丢失"类工单 = 0；24h 回访后会话可读率 100%（抽样）。

**对应 PRD**：R3.3、R3.7、R3.10、R3.6

**异常路径**

| 场景 | 系统行为 | 用户可见 | 验收点 |
| --- | --- | --- | --- |
| 取消某模型授权但成员正在使用 | 新请求返回 `MODEL_NOT_AUTHORIZED`；进行中会话降级提示 | 会话内提示"该模型已不可用，已切换到 X" | ≤30s 生效；不得中断正在流式输出的单条回复（允许该条完成） |
| 预算超限 | 网关返回 `MODEL_BUDGET_EXCEEDED`（429） | 显示重置时间 + 申请提升 | 阻断而非静默失败；计量不停 |

**对应 PRD**：R2.1、R2.2、R2.3、R2.4、R2.5、R2.6、R10.2
