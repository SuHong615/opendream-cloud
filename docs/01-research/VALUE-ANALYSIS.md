# OpenDream Cloud 价值分析（AI Native 基建）

> 修正：AgentCore 是运行时，AgentLoop 是质量/治理闭环，OpenCode Harness 是云边工程层，LoopForge 是流程编排，指挥中心是应用层。
> 总纲：[AI Native OS](AI-NATIVE-OS.md)

## 1. 一句话价值

OpenDream Cloud 让企业拥有自己的 **AI Native 基础设施**：运行时、质量闭环、云边 Harness、流程编排、数字军团指挥中心，承载任何业务的 AI Native 应用。

## 2. 平面价值

| 层 | 价值 | 指标 |
| --- | --- | --- |
| AgentCore | 统一 Agent 运行时，降低重复建设 | 接入时间、运行成功率、成本 |
| AgentLoop | 可观测/评测/实验/安全/沙箱/回测，质量可证明 | 评测覆盖、发布门禁、事故率 |
| OpenCode Harness | 云端/桌面快速构建与分享 | 首个应用时间、分享/复用 |
| LoopForge | 流程驱动角色数字人与军团 | 角色复用、战役完成率 |
| 指挥中心 | 数字孪生指挥、干预、复盘 | 干预时效、周期、成本 |

## 3. 不同用户价值

| 用户 | 价值 |
| --- | --- |
| AI Native Builder | 快速构建/接入/分享应用 |
| 领域专家/角色设计师 | 经验角色化、流程化、复用 |
| 开发者 | 扩展 AgentCore/工具/MCP |
| 质量/平台工程师 | 评测、实验、安全、回测闭环 |
| 指挥官/业务负责人 | 看得见、管得住、算得清 |
| 平台/IT | 私有化、治理、成本 |
| 高管 | 组合价值与转型 |

## 4. 经济价值

```text
收益 = 业务处理量 × 单件节省 + 新增产能 + 风险下降 + 工具成本下降
成本 = 平台 + 模型/算力 + 执行环境 + 人工审核 + 运营
ROI = (收益 − 成本) / 成本
```

## 5. 机会点

1. AI Native 基建层空缺；
2. AgentCore + AgentLoop 组合稀缺；
3. OpenCode Harness 云边一致；
4. LoopForge 流程驱动角色；
5. 数字孪生军团指挥中心新品类；
6. 私有化/开源替代；
7. 行业包/生态。

## 6. 价值验证

- 30 分钟首个应用；
- 4 周一条角色→军团→指挥闭环；
- 角色复用率 ≥ 40%；
- AgentLoop 发布门禁覆盖；
- 安全评审通过。

## 7. 反模式

- 只做聊天/Agent 市场；
- 只有编排没有运行时；
- 只有评测没有闭环；
- 只做应用不做基建；
- 角色不复用；
- 没有指挥中心；
- 没有真实执行。
